# 模型配置入口、目录与编辑器

本文描述拟议交互，适用于 GraphAgent Web 和 Electron。界面中的账号、价格和模型数值用于说明控件行为。现有快照、修订检查和出站调用仍以[当前前端契约](../../design/frontend-contract.md)为基线。

第二步用现有控件完成布局和交互，第三步接入条件计费，第四步再抽取可复用控件。[UI 实施方案](./ui-implementation-plan.md) · 封装目标见[共用 UI 表单设计](../../../common/ui/design.md#模型配置所需的公共表单)。

## 供应商页上的自定义供应商

当前可在创建表单中选择「New API 中转站」，填写站点和接入点名称。在接入点点击「站点模型目录」浏览公开挂牌，在账号行点击「模型配置」查看当前 Key 可见的目录，或点击「Key 与用量」访问该站点开放的个人令牌与额度接口。[模板交互与站点权限](../../../common/core/provider/new-api-template.md)

改版后，GraphAgent 的「服务商接入」页提供一个「创建自定义供应商」入口。填写名称与可选图标，为该供应商的协议族配置一次认证机制及允许的非秘密额外参数，再在各 offering 绑定族根地址、启用具体端点。族配置适用于该绑定的模型列表与推理请求，凭据随账号单独绑定。保存后新增独立 `providerId`，无需提前添加账号。模板始终可复用。

| 页面位置 | 用户可以做什么 |
| --- | --- |
| 内置供应商 | 查看接入点，在相应 offering 添加或管理账号。供应商定义由内置目录维护。 |
| 自定义供应商 | 按自己的名称和图标单独展示。在供应商层编辑名称、图标、offering 和端点，或删除这份配置。改名后账号和模型页继续引用同一 `providerId`。 |
| 自定义供应商下的 offering 和账号 | 在选定 offering 下添加或绑定账号。账号行提供启停、换 Key、解绑及「模型配置」。同一供应商有 CN、US 两个 offering 时，账号显示在它实际绑定的接入点下。 |

例如，用同一个模板先创建「中转站 A」，再创建「中转站 B」，页面上出现两个独立条目，创建入口仍在。两家都可以有一个叫 CN 的 offering。打开 A、修改 CN 的端点或给 CN 绑定账号，都只定位到 A 的 CN。模型页的供应商选择器列出实际供应商，模板只在供应商管理页用于创建。

**删除有账号引用的供应商。** 点「删除」先列出仍绑定的账号及所属 offering，停用账号也算引用。展示受影响的模型绑定和当前测试选择，供用户定位。只要还有账号引用，服务端拒绝删除，页面提供移到其他接入点或解绑的入口。解绑后可从待绑定账号入口重新接入，旧端点的目录与测试选择失去调用资格。用户处理完最后一个引用后重新执行删除；提交时再次检查引用。删除只作用于该条本地供应商配置，凭据及共享授权不随之删除。[账号及供应商的数据归属](../../design/business-database.md#账号凭据与自定义供应商)

2A 的共用页面将目录展开成 offering 行，并在 `compatible-api-key` 行上直接「添加账号」。2B 由 GraphAgent 提供自定义供应商条目和管理动作，按 `providerId` 定位供应商、按 `providerId + offeringId` 定位接入点。PolyQuota 沿用内置供应商入口，忽略共享凭据中的未知供应商引用。[当前供应商页](../../../../packages/shared-ui/src/providers/ProvidersPage.vue) · [当前目录投影](../../../../packages/shared-ui/src/presentation.ts)

## 两条入口，共用同一个编辑器

| 从哪里进入 | 首屏内容 | 下一步 |
| --- | --- | --- |
| 侧栏「模型配置」 | 「供应商」可选，「账号」等待选择供应商。具体模型详情暂不挂载 | 选供应商、接入点和账号或「全部账号」，再选协议族进入目录。只有一个可用族时直接进入，目录内可筛选具体端点 |
| 「供应商」页的账号行 | 在账号标识、认证标签旁提供独立的「模型配置 →」。打开时带入这行的供应商、接入点和账号 | 保留协议族切换入口；「返回供应商」还原展开的分组、滚动位置并将焦点送回原账号按钮 |

侧栏首次进入时不擅自选中第一行；已保存的测试模型单独显示为可点击的「打开当前测试模型」。从账号行打开的是具体账号，即便它继承供应商默认值也保持该账号的作用域。查看、切换或编辑模型都不会改动测试聊天选择，只有点「用于测试对话」才绑定本次选择。

### 选项如何区分

- **供应商**每个选项都带图标和名称，选中后仍显示图标。复用公共 UI 的 `iconKey` 映射，缺少素材时显示名称首字；同厂商多个接入点可在组内列作独立选项，例如「OpenAI / Codex 订阅」与「OpenAI / OpenAI API」，或「GLM / BigModel 国内」与「GLM / Z.ai 国际」。值保留 `providerId + offeringId`。[现有图标与展示投影](../../../../packages/shared-ui/src/presentation.ts)
- **账号**仅列当前供应商、当前接入点下可见的账号。每行显示公开名称和认证类型 tag，取自账号的 `authMethod` 与接入点的认证说明，如「浏览器 OAuth」「CLI 导入」「设备码」「API Key」；普通 Key 与订阅 Key 都可能使用「API Key」，用所在接入点或「订阅／自定义连接」副标签区分用途。同一组出现同名同类型时，再显示脱敏标识或稳定的短账号标识，保留可访问名称。邮箱只是文本，选择与跳转都按稳定 ID。
- **协议族与端点**分两层选择。`openai` 和 `anthropic` 分别对应各自的模型列表；在 OpenAI 族内切换 Chat Completions 与 Responses 时复用同一账号的目录。保存测试选择时仍指定一个可执行的明细端点。相同 URL 或模型名不会合并两个账号的目录。[当前账号与明细路由](../../../../packages/contract/src/graph-agent/models.ts)
- **当前定位**进入配置后保留「供应商／接入点／账号或全部账号／协议族」上下文，进入详情后另显示端点与操作。读屏和窄窗口也要能读全。账号行按钮可带可访问名称，如「配置 OpenAI Codex 下 dev@example.com 的模型」。无模型能力的账号行给出具体原因。共享供应商页通过由 GraphAgent 提供的行操作接入此入口；PolyQuota 继续使用自己的导航。[共用账号行](../../../../packages/shared-ui/src/providers/ProvidersPage.vue)

## 「全部账号」写入什么、从哪里读

「全部账号」是内置接入点的显式选择，供用户维护同组账号共用的模型配置。列表里和触发器里均标「供应商默认」，编辑页常驻说明「此配置应用于本接入点的所有账号，账号覆盖优先」。界面可同时显示已配置账号数。自定义兼容供应商只提供具体账号选项。

| 选择 | 配置保存范围 | 「刷新目录」读取来源 | 「用于测试对话」 |
| --- | --- | --- | --- |
| 内置供应商 · 全部账号 | 本接入点的明细端点、精确模型 ID 与操作默认值，新同组账号可继承 | 从获准、启用且支持所选族的账号中固定一个取样，显示账号、协议族与时间 | 选具体账号，并按所选明细端点核实资格后保存 |
| 内置供应商 · 指定账号 | 相同模型的账号级差异，可逐字段恢复供应商默认 | 刷新当前账号的该协议族 | 保存当前账号、明细端点与模型 ID |
| 自定义兼容供应商 · 指定账号 | 本 profile 内按供应商、offering、账号及明细端点保存，按操作编辑 | 从该账号所绑定 offering 的当前协议族读取列表 | 使用同一账号获准的明细端点 |

举例：A、B 都属于 Codex。选择「全部账号」，将某一模型的默认输出设为 2,048；B 单独覆盖为 1,024。A 和随后加入的 C 继承 2,048，B 仍显示 1,024。B 点「恢复继承」后当场看到 2,048 及「供应商默认」来源，保存后生效。若模型只在 A 的远端目录出现，B 的配置仍可继承，实际发送前须检查 B 的可执行模型、协议与绑定。

**数据与失败策略。** 默认配置独立保存一份，不向各账号复制，也不随凭据写入 broker。远端目录按可见范围、供应商、offering、账号、协议族及 `familyBindingRevision` 缓存，刷新时核验当前权限。公共视图注明实际取样账号；该账号的报价、授权、远端限制和手工登记各自保留来源。首次可按稳定顺序选合格账号，重复刷新优先沿用仍可用的上次来源。用户显式重试可选择另一账号，页面更新来源。暂时失败保留同一有效绑定上次成功快照及时点；没有可用来源时，显示已有默认配置及「暂无可用于读取目录的账号」。

**刷新请求的验收。** 两个账号的 OpenAI 族目录同时过期。进入「全部账号」后点击刷新，只向一个合格账号的 OpenAI 族拉取一轮完整分页。在该账号内切换 Chat Completions 与 Responses，复用在途请求或同一成功快照。切到另一个账号或 Anthropic 族时只刷新新范围。SSE 重读页面不会再次触发该次刷新。原生客户端单独请求模型列表时，仅收到它请求的一页原生响应。[现有快照与刷新逻辑](../../../../apps/graph-agent/src/server/model-service.ts)

**字段覆盖。** 拟按字段依次使用当前账号覆盖、显式供应商默认覆盖、当前账号路由的明确值、精确型号预置、同代系列允许继承的字段、未知。调用参数还须满足协议和实际账号的执行约束。例如，用户可以推荐一个输出上限，但远端已明确的硬上限仍参与校验。恢复继承会删除本层覆盖，显式「未知」是一个可保存的值，两者需有不同操作。系列、数据来源与可继承字段详见[模型预置与字段继承](../../../common/core/provider/model-structure.md#同代变种如何套用参数)。

## 目录筛选

用途与输入、输出维度参考 [OpenRouter 模型接口](./implementation-references.md#openrouter-提供了哪些参考)。

选择「供应商 → 接入点 → 账号或全部账号 → 协议族」后浏览目录，再按明细端点和用途筛选。筛选栏位于目录上方，不打断右侧编辑。账号目录显示本账号和所选族；「全部账号」注明取样账号；预置库标明「仅供参考」。不可见的账号及其专属模型、数量、价格不参与列表或选项计数。[现有目录投影](../../../../packages/contract/src/graph-agent/models.ts)

| 筛选项 | 选项及显示条件 |
| --- | --- |
| 用途 | 对话、图像生成、视频生成、音乐生成、向量嵌入、重排序、语音合成、语音转写、决策。一个模型可出现在多个用途下；每项关联单独的 `operationId`。 |
| 输入 / 输出 | 分别显示文本、图像、视频、音频、文件、选择，并在适用方向显示向量、分数。例如嵌入操作输出向量；同一张音频标签可用于 ASR 的输入，也可用于 TTS 的输出。文件类型、最大上传大小等细化条件来自已打开操作的规格。 |
| 参数与能力 | 选择了用途后再提供适用条件，如对话的结构化输出、图像生成的尺寸、嵌入的向量维度、转写的时间戳、决策的二值判断或选项排序。无上下文窗口定义的操作显示「不适用」。 |
| 工具关系 | 「可发起工具调用」筛调用方操作是否支持工具；「可作为工具执行」筛可被挂载的目标操作。若已指定对话模型，可进一步选「此对话可调用」，要求存在从这个调用方到目标操作的有效绑定，并满足当前账号权限。 |
| 价格与套餐（第三步） | 先选 API 按量或订阅，再选费用维度，例如输入百万 tokens、一次请求、一张图、一个计费单位的字节数或生成秒数。价格上限和升序排序仅比较同一维度、币种、单位及适用条件下的报价。 |
| 来源与状态 | 远端目录、手工登记、精确预置、系列参考可以并存，分别显示目录来源和字段来源。「可执行」「仅参考」「暂不可用」「待核实」各有文字提示；隐藏不可用项可以随时取消。 |

搜索匹配公开模型名、精确上游 ID、原厂家族与系列。可在结果中按模型折叠多个操作，展开时显示每个匹配操作的模态、账号、协议、价格适用条件和取数时点。每条行动入口带具体操作名，如「用于对话」「生成图像」「运行决策」。当前版本只实现单轮测试聊天，其他操作随对应适配器落地后才开放执行。

## 查询语义

1. **同一次调用满足条件。** 每个候选匹配项定位到当前上下文中的一个账号绑定、精确模型 ID、`operationId` 和一个 `ioProfiles` 条目。输入、输出、参数、报价和工具关系均在这条路径上检查。模型必须至少有一个匹配项才入选，返回匹配项用于解释理由。按模型折叠时以当前范围内的稳定 ID 去重，不按显示名去重。
2. **多选有明确含义。** 多个用途或多个系列默认「任一」。不同筛选组之间为「全部」。输入和输出组各自提供「任一／全部」，其中「全部」要求同一输入输出组合支持所有勾选项。上游为两种替代输入分别声明的组合不能拼接。输出条件指该组合实际能产生的结果类型，并列的可替代输出也需分组合表示。
3. **区分能力检索与现有请求。** 普通浏览中，输入可选集合取该组合 `requiredInputs ∪ optionalInputs`。勾选「按当前请求匹配」时，传入本次实际提供的模态集合 `given`，要求 `requiredInputs ⊆ given ⊆ requiredInputs ∪ optionalInputs`，并检查必要的文件格式、数量约束等。例如，要求「文本+参考图」的图像编辑操作可在“支持文本”的能力检索中出现，用户只提供文本时则不能直接发起该编辑操作。
4. **缺失值单列。** 对每个相关条件区分已满足、明确不符、缺少证据。默认只返回满足筛选项的结果；勾选「包含待核实」时，另列仍可能匹配的候选并指出缺少哪个字段。已知不符始终排除。没有输入输出组合、价格、端点能力或实现绑定时保留未知，禁用或撤权按账号状态立即处理。「无筛选」可以浏览在权限范围内的未知记录。
5. **比较相同的钱。** 已知输入 token 价可精确换算为同币种的每百万输入 tokens 单价。单次费率、每秒、按大小、订阅额度与未定价项目另分组。若要比较整次任务费用，需指定相同的输入量、输出量、尺寸/时长、请求时刻、套餐等，按各自规则求总价后再排序。缺少报价条件显示「需要时段／用量」；明确零价可以参与排序。未知价或套餐内用量不默认为零。[计费规则](../../../common/core/provider/model-pricing.md)
6. **控制筛选的效果。** 每项筛选都显示可移除的标签，零匹配时给出清除单项和清除全部两个入口。分组计数基于同一可见快照，按当前其他分组条件计算，标明「模型数」或「操作数」。筛选、展开和隐藏只改变视图；切换账号、撤权和变更绑定会重算可见性，点击执行时服务端再检查当前绑定与能力。

以下示例为拟议的本地查询。用户给当前对话准备一个能接收文本提示并产出图像的工具，已经提供的输入只有文本。调用方引用和目标目录范围分别定位，示例中的账号与操作引用均为虚构值。

```json
{
  "scope": {
    "mode": "account",
    "providerId": "example-gateway",
    "offeringId": "standard-api",
    "accountId": "image-account",
    "protocolFamily": "openai",
    "protocol": "openai-images-generations"
  },
  "filters": {
    "operationIds": { "anyOf": ["image-generation"] },
    "requestInputs": { "given": ["text"] },
    "outputModalities": { "allOf": ["image"] },
    "tool": {
      "role": "target",
      "callerRef": "saved-chat-binding-01"
    },
    "availability": "executable",
    "includeUnknown": false
  }
}
```

返回结果应指出是哪个图像操作及哪种输入配置匹配、该对话通过哪个绑定调用它。聊天模型本身能接受 `tools`，仅证明调用方条件之一；上下游操作、协议、授权或工具关系缺失时，执行动作附具体原因。查询条件只含公开 ID 和枚举，不接收凭据或任意目标 URL。

### 筛选验收

| 输入或操作 | 期望结果 |
| --- | --- |
| 同一模型在聊天路由支持图像输入，另一个嵌入路由只收文本。筛「图像输入、向量输出」 | 无匹配。单独筛「嵌入」能找到文本嵌入操作。 |
| 查询「输出音频」并勾选音乐生成、TTS 两个用途 | 展示两种匹配用途。取消 TTS 后剩音乐生成；ASR 音频输入且文本输出，不属于此结果。 |
| 两个模型都能返回 JSON，只有一个注册了可执行的二值决策操作 | 筛「决策、输出选择、二值」只返回已声明相应契约的操作。底层由 LLM 驱动的有效封装也可入选。 |
| 一条重排操作返回带分数的文档顺序，一条决策操作返回选项排序 | 按返回契约将两者投影到对应结果形态；将用途设为 `rerank` 或 `decision` 可区分任务。 |
| 当前对话可调用的图像工具、可直接调用的图像服务和普通工具调用型聊天模型出现在同一目录 | 指定「此对话可调用＋输出图像」仅显示有效工具目标。具备直接图像能力的条目可由「图像生成」找到。 |
| 已知零价、无费率、订阅剩余额度、按张、按百万 tokens、峰谷时段各有候选 | 切换计价维度后仍能解释入选理由。未给时间或用量时，无法唯一确定档价的行不参与同价排序；各条件解析后价格相同者可以比较。 |
| 发现 API 默认只返回文本，或聚合记录只提供宽泛的模态集合 | 完整同步时可找到图像、嵌入与决策等条目；无法证实的具体输入输出组合标记待核实。分页或局部筛选的结果不会把其他类别清空。 |

## 模型编辑器

目录区负责搜索上游 ID、选择模型、刷新目录及登记手工模型。选中模型后，详情标题展示精确模型 ID，左侧保留目录，右侧提供三个页签。窄窗口将目录折叠为可返回的列表，编辑表单变为单列。目录持久化成功的空列表、连接未就绪、读取失败且有缓存需分别显示；没有列表接口的网关仍可按精确 ID 登记并测试。

**按用途打开详情。** 已选账号或「全部账号」后，目录支持同时筛用途、输入、输出、工具关系和计价条件。同一个模型命中多个操作时显示命中的操作，选定操作后再呈现详情。例如音乐和 TTS 都可输出音频，用户可先按音频找到二者，再按用途缩小范围。保存、草稿恢复及测试绑定均携带操作和输入输出 profile。设计中的试调用随执行器开放；Decision 使用候选项结果板，向量使用维度与条目，媒体使用资产预览，聊天使用现有对话页。[目录筛选规则](#查询语义) · [用途和结果类型](../../../common/core/provider/model-structure.md)

### 能力与限制

控件随操作切换。生图显示尺寸和张数，视频显示分辨率和时长，音乐与 TTS 分别展示风格和音色，ASR 展示语言与时间戳，向量与重排分别展示维度与 top K，决策展示支持的决策模式与候选数。下表是聊天操作的字段示例。有效值显示在可编辑控件内，每个字段仅出现一次。较多字段按下表分组，容量和模态默认展开；支持的操作、工具及高级限制可以收起。字段名始终可见，参数编辑不使用「选择字段 → 共用值框」。枚举下拉只用于该字段自身的合法取值。

| 分组 | 字段 | 控件与行为 |
| --- | --- | --- |
| 容量限制 | 上下文窗口、最大输入、最大输出 | 独立正整数输入，固定单位 tokens，未知有独立状态。把模型最大输出与「调用参数」中的本次输出预算分开标注 |
| 模态与操作 | 输入模态、输出模态、可用操作 | 标签多选。新增或删除单个值；明确空集显示「无」，无来源显示「未知」。不需要键入分隔符或 JSON |
| 工具与输出 | 视觉、工具调用、并行工具调用，结构化输出 | 能力用「支持／不支持／未知」三态控件；结构化输出单独选「不支持／JSON／JSON Schema／未知」 |
| 推理 | 推理模式、支持的强度、默认强度、可公开的思考内容 | 模式枚举、强度多选、默认强度单选。展示当前模型与端点能返回全文、摘要、活动或尚待核实；标出资料来源。默认强度不在支持集合中时就地指出矛盾，保留其他草稿 |
| 缓存与约束 | 缓存读、缓存写、不接受的参数 | 读写分别用三态控件；不接受的参数用可增删的标签输入 |

控件旁显示来源短签，如「远端目录」「型号预置」（精确命中）「系列参考」「供应商默认」「当前账号覆盖」。可展开查看具体来源、版本和日期，仅对有本层覆盖的字段提供「恢复继承」。修改后显示脏状态，仍可在同页看见相邻参数值。参考值或未知也不等于该账号具备推理权限。

**选择参数参考。** 在模型标题旁显示当前关联，如「GPT › GPT‑4.1 › mini」。打开「更换参考型号」可按原厂、系列、变种搜索或选择「使用系列参考」。应用前展示哪些字段会随参考变化，以及哪些字段已有账号覆盖。应用后可继续在原表单逐项微调；恢复「自动匹配」重新解析当前清单。手工关联始终保留目录中的原始模型 ID 和请求地址。[匹配与继承方案](../../../common/core/provider/model-structure.md#同代变种如何套用参数)

### 调用参数

每个操作从自己的参数模板生成控件。以聊天为例，能力页的「最大输出」描述模型上限，这里的「请求输出上限」是一次调用的预算。用分组的专用控件编辑请求输出上限、上下文预算、推理强度、温度和 Top P。温度、Top P 支持小数及 0，各协议不接受的参数给原因。上下文预算沿用当前标准协议的本地约束语义，不在预览里虚构出站字段。保留「协议默认」状态，避免把空值保存为零。

「预览请求」为次级动作，按当前草稿生成脱敏结构，预览区注明作用域、协议和是否为未保存值。选「全部账号」时，先显示本次预览采用的具体来源。预览不替用户保存。实际聊天使用已保存、已核验的账号选择；若要以草稿开始测试，明确提供「保存并用于测试对话」。[现有预览与选择命令](../../../../packages/contract/src/graph-agent/models.ts)

聊天参数首先显示「支持思考」，默认开启。打开后才能编辑「思考强度」和「返回完整思考内容」，后者默认关闭。强度选择来自该绑定允许的档位，可选「协议默认」。全文选项旁说明实际能返回的内容；仅有摘要或仍待核实时禁用全文选项并给出原因。关闭前置开关后，两个子控件禁用，预览撤掉已选强度与全文请求，保存后重开仍显示关闭。对始终推理的型号，控件旁说明该开关仅控制调用参数与展示。[思考参数与可见输出](../../../common/core/provider/model-structure.md#思考参数与可见输出)

### 价格

**第二步**只编辑普通输入和输出两项单价、币种和固定分母，每百万 tokens 分别计价，旧条件报价按原值保留。

**第三步**再按操作及接入产品（API 或订阅）编辑所引用的价目表。API 页按行展示计量项、金额、币种、分母数量与单位、条件和来源。按次、像素、字节、字符、媒体时长等与 token 并列可选，订阅页另有周期费、包含额度与超额规则。展开条件可设置整档／累进阈值，或设置峰谷时间、时区与日历；通过样例负载预览命中的规则及各行费用。旧图展示普通 token 价行，新图展示条件价。[价目表和验算样例](../../../common/core/provider/model-pricing.md)

第三步可分别设置输入、输出、缓存及其计费条件。金额以非负十进制字符串保存，零显示为 0；无报价显示「未知」。输入百万 tokens 的 USD 价格与输出、缓存读取、缓存写入各自独立；不同币种、单位、档位或时长另起行，不自行折算。添加新行、恢复某一报价继承、移除自建行均就地进行。变更计量单位时提示重新核实已有金额；收费行与规则分别有稳定 ID，旧计价口径的覆盖不会误套到新单位。示意图的价格仅用于核对交互。

### 保存、切换和恢复

1. 页面维护当前模型和作用域的一份草稿，跨页签保留。底栏显示改动数和「放弃更改／保存更改」。一次提交同一模型所有脏字段及报价；保存成功后以服务器确认的有效值和来源重绘。仅激活某个控件不计改动。
2. 切换供应商、账号、协议、模型、操作或价目表，或离开页面时，有草稿则提供「保存并继续／放弃更改／继续编辑」。主动放弃仅回退本次未保存部分。保存失败停留原处，展示字段级诊断；错误摘要能将焦点带到对应页签和字段。
3. 后端切换、断开或账号撤权时取消关联的读取与预览，迟到响应只可用于原作用域。若仅修订冲突，显示发生冲突的字段，允许对照最新值重新应用；若账号已不可见，立即清除其详情与草稿。目录刷新校验 `familyBindingRevision`，完成后展示该快照的 `catalogRevision`，试聊发送校验明细 `bindingRevision`；配置写入沿用 `expectedSettingsRevision`。
4. 阶段二当前将 `ModelParameters` 放在已保存的测试选择中，账号默认值与「全部账号」作用域尚需产品服务支持。后续实现应将模型编辑保存与测试选择拆开，并为同一草稿的批量修改提供单次校验、一次提交的服务语义，避免若干独立 HTTP 写入造成部分成功。2B 从当前 profile 的 SQLite 读取已保存的账号覆盖，重开时按经核实的账号引用恢复。[现有设置存储与命令](../../../../apps/graph-agent/src/server/model-service.ts)

| 同一品牌有国内和国际接入点，两把自定义 Key 共用地址 | 目录按 offering 和账号隔离。只换某账号的 Key 会使该账号引用该 Key 的各族绑定失效。修改 CN 的 OpenAI 族根地址时，CN 内该族的目录及受影响账号的明细端点均须重验；US 与 CN 的其他族继续使用各自绑定。仅调整 CN 图片编辑的端点操作配置时，族目录与图片生成仍可用 |
| 一次修改容量、模态、工具与报价 | 所有值可同时核对；一次保存全部生效。切页签不丢草稿。恢复单字段继承后显示下层来源，其他字段不变 |
| 打开仅存了推理强度的旧模型，再切换「支持思考」 | 首次显示前置开关开启、原强度、全文关闭。关闭并保存后，草稿、预览与重开的有效参数均为关闭，试聊请求没有残留强度。 |
| 为支持全文的 DeepSeek 绑定开启全文，再切到仅公开摘要的绑定 | 前者的思考节点包含按顺序收到的全部公开文本；后者标明摘要能力并禁用全文，签名与加密块不出现在节点中。 |
| 第三步编辑缓存报价金额 0、未知、删除覆盖 | 三者分别可录入、显示及恢复，含档位或时长的报价不会覆盖另一行 |

| 编辑中改绑、撤权或后端切换 | 迟到数据不覆盖新页面，不会把旧草稿写给新账号；只读状态说明原因 |
| 键盘操作与窄窗口 | 可以按键盘完成供应商、账号、模型、表单和保存全过程；返回账号行后焦点可预测，错误能定位，关键状态有文字 |
