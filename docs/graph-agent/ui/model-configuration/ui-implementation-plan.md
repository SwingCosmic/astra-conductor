# GraphAgent 模型配置 UI 实施方案

本方案接续供应商与 Core 完成的数据结构改造。交付顺序为 **① 数据结构与接入点 → ② 布局和交互 → ③ 计费支持 → ④ 公共 UI 组件封装**。首轮界面只配置每百万输入、输出 tokens 的基础单价。供应商阶段三的别名与自定义参数转换沿用原计划。[供应商与 Core 数据实施方案](../../../common/core/provider/implementation-plan.md#模型配置改版的数据实施方案)

## 2B 界面交付与验证

GraphAgent 的供应商页已接入本地自定义供应商管理。通过模板可创建含多个 offering 的实例。账号仍有引用时，页面列出所属接入点和可见的模型影响，用户可以移走或解绑账号。对于只有凭据、缺少本地供应商定义的账号，页面提供「配置此账号的供应商」，宿主核实凭据身份后以原供应商 ID 建立定义，再由用户明确选择 offering。[供应商页](../../../../apps/graph-agent/ui/src/pages/CustomProvidersPanel.vue)

模型编辑器按供应商、offering、账号范围和端点定位模型。能力与限制、调用参数、价格三个页签使用同一份草稿。参数控件由操作模板生成，价格页支持按套餐编辑价卡、设置阶梯与时段、订阅权益和试算。保存后可单独设置测试模型。共用表单字段、供应商图标与原生弹窗已用于两个产品的界面。[模型编辑器](../../../../apps/graph-agent/ui/src/pages/ModelFactsPanel.vue) · [条件价卡](../../../../apps/graph-agent/ui/src/pages/RateCardEditor.vue) · [共用控件](../../../../packages/shared-ui/src/index.ts)

2026-11-15 的 Electron 烟测经过沙箱 Vue 页面、产品 Hono 服务和隔离的 SQLite profile。测试在同一 offering 配置两个图片端点并绑定相同模型 ID，峰时 HD 五张图试算 0.40 USD，排除日历命中后为 0.30 USD。文本模型保存基础价格和调用参数后完成预览、选用、单轮问答和费用展示，实扣样本为 0.015 USD。停用账号仍阻止删除供应商，解绑后可删除并通过原账号显式重建、重新绑定。在 640 × 840 窗口通过 Enter、Tab、Escape 验证弹窗焦点以及从模型配置返回原账号行。上述协议响应由受控上游提供。公共组件 14 项和 PolyQuota 界面 65 项回归通过。[Electron 烟测](../../../../apps/graph-agent/test/desktop-smoke.mjs) · [价目投影测试](../../../../apps/graph-agent/test/model-quotes.test.ts)

同日的代码审查确认界面交互与 [interaction.md](./interaction.md) 及 [前端契约](../../design/frontend-contract.md)一致。审查记录的四项待收敛中，目录报价展开已改由服务端投影（`model-quotes.ts`）随 DTO 下发，界面仅做筛选与排序；其余三项仍待收敛：`ModelFactsPanel` 的来源短签、费用状态文案与 `catalog-labels.ts` 分散多处，宜归并为一处标签表；推理强度候选值写死在编辑器，应随目录条目的 `effortLevels` 下发；自定义供应商行依赖 `"custom-"` ID 前缀判断并写死 `API Key` 认证标签，应由 DTO 显式标记。

## 第一步的交接条件

Core 和 GraphAgent 服务先提供带 `providerId / offeringId / accountId / protocolRouteId` 的公开目录、操作与输入输出组合、逐字段来源、作用域及草稿保存命令。UI 使用 GraphAgent 业务库生成的快照和同一套 HTTP/SSE 契约。接入点验收数据包含同一 OpenAI 供应商下的 Codex 订阅与官方 API Key，以及一个含 CN／US 两个 offering 的自定义供应商。每个账号只绑定一个 offering。供应商页维护名称、可选图标和该 offering 的各协议 URL，账号行维护展示名、启停和凭据动作。指定的 2A 共享测试库从零个自定义供应商开始验收。另用隔离夹具验证待绑定账号的提示。[多 offering 验收](../../../common/core/provider/implementation-plan.md#openai-的两个-offering) · [现有产品契约](../../design/frontend-contract.md)

## 第二步：布局和交互

| 页面 | 要做的修改 | 用户能验证的结果 |
| --- | --- | --- |
| 供应商信息展示与管理 | GraphAgent 提供可重复使用的「创建自定义供应商」模板。每次保存增加一个独立的供应商条目，提供编辑、删除和按 offering 绑定账号的操作。 | 连续创建 A、B，两家各有 CN。重启后两项及创建入口均可见。修改 A 的名称或端点只改变 A。有账号引用时删除被阻止并列出引用，逐个移走或解绑后可删除 A。B、模板和共享凭据仍可用。[完整交互](./interaction.md#供应商页上的自定义供应商) |
| 供应商页与模型页入口 | 支持模型的账号行增加「模型配置」，携带具体接入点和账号。从侧栏进入先选带图标的供应商；有多个 offering 时明确选择接入点，再选带认证类型标签的账号。单一接入点直接带入。 | 同一 OpenAI 分组下看得见「Codex 订阅」和「OpenAI API」。两个账号即使同名，目录、认证标签、协议与返回焦点仍对应原账号。浏览设置期间保留原来的测试选择。 |
| 目录与范围 | 内置接入点允许选「本接入点全部账号」及其协议；自定义服务始终选具体账号。显示取样账号、目录时间、可用操作，支持刷新和手工登记。用途、输入、输出匹配同一部署和操作的同一个组合。 | 两个接入点都有同名模型时，共享默认各自生效。公共视图只请求一个获准账号，撤权或改绑后的迟到结果不会写回。列表接口返回 404 仍可手工登记并试聊。 |
| 模型编辑器 | 将能力与限制、调用参数、价格分组。每个字段就地呈现值、来源和自己的控件，删去重复展示区和通用字段输入框。切换页签保留草稿，一次保存；离开、冲突与恢复继承按字段反馈。 | 可同时复核窗口、模态、输出预算和单价。任一字段失败时保留整份草稿；成功后重启读回。单轮测试发送服务端已保存的具体绑定。 |
| 预置数据 | 在目录或设置中显示生效修订，提供导入、更新和回滚操作，调用第一步的数据服务。 | 离线启动可读首批家族；导入失败保留旧修订和本地覆盖。 |

**首轮价格表单。** 选择一种明确币种，分别填写「输入单价」「输出单价」，在两个输入框旁固定标明「每 1,000,000 tokens」。两项独立修改，允许十进制零价，未取得价格显示未知，「恢复继承」删除本层覆盖。保存只提交用户修改的报价键；已有缓存读写、其他币种或条件报价原样保留，有此类记录时显示只读提示。输入 0、输出 2.50 的样例应能保存并重启回读；清除输入覆盖后恢复其下层值，输出和其他价行不变。

本步直接使用产品页面、现有公共壳和图标完成交互。账号行可增加供 GraphAgent 注入的动作，字段在页面内用已有控件实现。窄窗、键盘选择、错误聚焦和取消编辑在本步验收。缓存条件、峰谷和试算画面用于第三步。[交互设计](./interaction.md)

## 第三步：接入计费支持

在 GraphAgent 自定义供应商的 offering 下，分别登记图片生成、图片编辑和其他可配置端点。模型编辑器根据类型、操作和输入输出组合筛选该账号可绑定的端点，持久化配置并验证，不发送媒体请求。[端点配置与绑定验收](../../../common/core/provider/implementation-plan.md#自定义-api-端点与模型绑定)

数据侧价卡与计算契约就绪后，扩展同一价格页，按操作、接入产品和套餐展示可用计量项。现金零价、订阅含量、未知分别显示。输入同一份样例负载，展示所用版本、命中档位或时段、行金额与总价；单轮结果区标明估算或回执来源。[Core 计费实施步骤](../../../common/core/provider/implementation-plan.md#第三步计费数据与计算)

- 在基础价格上增加缓存、按次、大小／时长等计量、阶梯与峰谷编辑，提供订阅和超额规则。用带时区的峰谷边界及相同型号的 API／订阅两张价卡回归。
- 启用价格和套餐筛选，只在同币种、同计量和适用条件下排序。用未知、套餐内及明确零价三个条目验证显示结果。
- 已有简单 token 单价继续可读、可改，并可按旧值试算。历史会话账本随执行产品交付。[报价与回执样例](../../../common/core/provider/model-pricing.md#验收样例)

## 第四步：封装公共 UI 组件

布局、保存语义和计费控件通过验收后，对照 GraphAgent 和 PolyQuota 已落地的用法，将重复的字段布局、带图标和标签的选择器、数值／金额输入、弹层焦点与保存栏提取到 `packages/shared-ui`。按实际复用需要选用 shadcn-vue 的字段组合或 Reka UI 原语，产品服务继续负责授权、作用域和计费规则。[公共组件职责与选型](../../../common/ui/design.md#模型配置所需的公共表单)

以相同样例在封装前后核对 GraphAgent Web/Electron 的账号跳转、跨页签草稿和计费试算，再回归 PolyQuota 的连接编辑、凭据取消、键盘与主题。两端通过后再替换其余重复实现。
